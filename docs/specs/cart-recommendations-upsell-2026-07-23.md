# Spec: Cart Recommendations — قسم «أكمل طلبك» في سلة التسوق

## السياق والمبرر

Salla أطلقت في v2.14.501 (15-07-2026) ميزة "Gap Cart Recommendations" — قسم داخل سلة التسوق يعرض منتجات مقترحة لزيادة متوسط قيمة الطلب (AOV). النمط نفسه موجود في Shopify (Quick Add in Cart) وهو معيار صناعي مثبت.

`CartDrawer.tsx` في dasm-stores يعرض حالياً: قائمة عناصر السلة + ملخص الإجمالي + زر «إتمام الطلب». لا يوجد أي قسم توصيات. إضافة قسم بسيط بـ 2-3 منتجات من نفس المتجر تحت قائمة العناصر تُحسّن AOV دون تعقيد تجربة الدفع.

---

## الحالة الراهنة في dasm-stores

**الملف المعني:**
- `components/cart/CartDrawer.tsx`

**السلوك الحالي:**
الـ drawer يعرض `CartItem` لكل عنصر في السلة، ثم ملخص السعر، ثم زر «إتمام الطلب». لا يوجد أي استدعاء لمنتجات أخرى من المتجر داخل الـ drawer.

**API المتاح:**
`getProducts(slug, { sort: "featured", per_page: "6" })` في `@/lib/api-server` — يعيد منتجات المتجر ويمكن استخدامه لجلب توصيات.

## التغيير المقترح

### المكوّن الجديد: `CartRecommendations`

```typescript
// TypeScript signature (مرجع فقط — ينفّذه Cursor)
type CartRecommendationsProps = {
  slug: string;             // slug المتجر
  excludeIds?: number[];    // معرّفات المنتجات الموجودة في السلة (لاستبعادها)
  limit?: number;           // افتراضي: 3
};
```

### Variants

| Variant | الوصف |
|---------|-------|
| `default` | 3 بطاقات منتج أفقية بسيطة: صورة صغيرة + اسم + سعر + زر «إضافة» |
| `compact` (mobile) | بطاقتان فقط، صورة مصغّرة أكثر |

### States

| الحالة | السلوك |
|--------|---------|
| `loading` | هيكل skeleton بـ 3 عناصر (تجنّب layout shift) |
| `empty` | لا يظهر القسم (إخفاء كامل — لا رسالة «لا توجد توصيات») |
| `error` | لا يظهر القسم — لا يُعرض خطأ للمستخدم |
| `all in cart` | إذا كانت جميع المنتجات المُقترحة موجودة في السلة، يُخفى القسم |

## معايير القبول

- [ ] القسم لا يظهر إلا إذا عاد الـ API بمنتج واحد على الأقل غير موجود في السلة
- [ ] النقر على زر «إضافة» يضيف المنتج للسلة ويحدّث عداد السلة دون إغلاق الـ drawer
- [ ] لا يظهر القسم للسلات الفارغة
- [ ] القسم يأتي بعد قائمة العناصر وقبل ملخص الإجمالي (ترتيب: عناصر → توصيات → إجمالي → زر الدفع)
- [ ] الصور في حالة `loading` محجوزة بـ skeleton بنفس الأبعاد
- [ ] يعمل بالـ RTL (dir="rtl")

## مخاطر التغيير

| الخطر | التخفيف |
|-------|---------|
| بطء تحميل الـ drawer بسبب استدعاء API إضافي | استخدام `Suspense` + skeleton؛ جلب خلفي (background fetch) |
| ظهور منتجات موجودة في السلة ضمن التوصيات | `excludeIds` — تصفية من جانب العميل بعد الجلب |
| تعارض مع تجربة الدفع | القسم يأتي قبل الإجمالي — لا يطغى على زر «إتمام الطلب» |
