# Spec: Review Summary Bar — ملخص التقييمات على صفحة المنتج

## السياق والمبرر

Salla أصدرت Twilight v2.14.490 (08-07-2026) بدعم تقييمات متعددة المعايير وملخص مرئي للتقييمات. يُظهر ملخص النجوم (الوسط + التوزيع) في أعلى قسم المراجعات ثقةً أعلى وقراراً شراء أسرع. الدراسات تُظهر أن عرض توزيع النجوم يرفع نسبة الشراء بنسبة تصل إلى 18% مقارنة بعرض المراجعات الفردية فقط.

## الحالة الراهنة في dasm-stores

### الملفات المعنية

- `components/product/ProductReviews.tsx` — المكوّن الحالي للتقييمات
- `app/[slug]/products/[productId]/page.tsx` — السطر 118: `<ProductReviews reviews={product.reviews} />`

### السلوك الحالي

`ProductReviews` يعرض فقط:
- قائمة `<ul>` من المراجعات الفردية
- كل مراجعة: 5 نجوم + اسم العميل + عنوان + نص

المفقود:
- لا متوسط مرئي للتقييم
- لا شريط توزيع (كم مراجعة لكل مستوى 1–5)
- لا عدد إجمالي للمراجعات بارز
- لا ملخص سريع يمكن قراءته دون التمرير

## التغيير المقترح

### إضافة مكوّن `ReviewSummary` داخل `ProductReviews.tsx`

يُحسب من `reviews[]` المتاحة بالفعل — **لا تغيير في الـ API**.

### الواجهة (TypeScript signature)

```typescript
// داخل ProductReviews.tsx — props لا تتغير
export function ProductReviews({ reviews }: { reviews: StoreReview[] | undefined })

// مكوّن مساعد داخلي (لا يُصدَّر)
function ReviewSummary({ reviews }: { reviews: StoreReview[] })
```

### المكوّنات البصرية لـ ReviewSummary

**1. الوسط + العدد الإجمالي** (أعلى يسار الـ section):
- رقم كبير: متوسط التقييم (مثل `4.3`) بجانب `⭐` مملوءة
- نص صغير: `(23 تقييم)`

**2. شريط التوزيع** (5 أسطر: من 5 نجوم إلى 1):
```
5 ⭐ ████████░░  18
4 ⭐ ████░░░░░░   4
3 ⭐ █░░░░░░░░░   1
2 ⭐ ░░░░░░░░░░   0
1 ⭐ ░░░░░░░░░░   0
```
- الشريط: `div` بعرض نسبي (`count / max * 100%`)
- لون: `bg-[var(--c-brand)]` للجزء الممتلئ، `bg-[var(--c-surface-2)]` للفراغ

**3. فاصل** بين الملخص وقائمة المراجعات الفردية

### Variants

| variant | متى |
|---------|-----|
| بلا ملخص | `reviews.length === 0` — النص الحالي "لا توجد تقييمات بعد" |
| ملخص بسيط | `reviews.length === 1` — عرض النجوم فقط دون شريط التوزيع |
| ملخص كامل | `reviews.length >= 2` — كامل المكوّن |

### سلوك states

| state | السلوك |
|-------|--------|
| `loading` | المكوّن server component — لا loading state منفصل |
| `empty` | النص القائم "لا توجد تقييمات بعد" — لا تغيير |
| `error` | إذا أعاد الـ API `reviews: undefined` — المكوّن يتحمل بدون crash (الحالة الراهنة محمية) |

## معايير القبول

- [ ] يظهر متوسط التقييم (رقم عشري موضّب لمنزلتين) في أعلى قسم التقييمات
- [ ] يظهر العدد الإجمالي للتقييمات بجانب المتوسط
- [ ] يظهر شريط التوزيع للمستويات 1–5 بعرض نسبي صحيح
- [ ] الشريط يستخدم `var(--c-brand)` للامتلاء ليتوافق مع ثيم المتجر
- [ ] عند تقييم واحد: يُعرض المتوسط دون شريط التوزيع
- [ ] عند لا تقييمات: لا تغيير في الحالة الراهنة
- [ ] RTL صحيح: النص يبدأ من اليمين، الشريط يمتلئ من اليمين
- [ ] لا استدعاء API جديد — يعتمد 100% على `reviews[]` المُمرَّرة

## مخاطر التغيير

- **منخفضة:** تغيير pure UI داخل مكوّن عرض، لا جانب خادم، لا state جديد
- **تحقق:** إذا كانت `reviews[]` تحتوي قيم `rating` خارج النطاق 1–5، يجب تصفيتها عند حساب المتوسط (`r.rating >= 1 && r.rating <= 5`)
- **أداء:** الحساب O(n) على مصفوفة صغيرة — مقبول دون memoization
