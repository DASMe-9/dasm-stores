### 2. بنية Hero ومشهد التجارة المتحرك — **HIGH**

| | التفصيل |
|--|---------|
| **الملف** | `app/page.tsx` |
| **الـ baseline** | hero داكن (`bg-[#021b1f]`) بعرض كامل، تصميم أحادي العمود يحتوي على `HeroScene` (أيقونات متحركة: حقيبة تسوق، سماعات، عطر، ساعة، سلة) مع شريط بحث مضمَّن أسفله |
| **الكود الحالي** | قسم فاتح (`bg-[#eaf2f1]`، شبكة `lg:grid-cols-[1.05fr_.95fr]`) — العمود الأيسر نص فقط، العمود الأيمن مكوّن `CommercePassport` — لا `HeroScene` |
| **الـ commit المسبِّب** | `013f987` (2026-07-30) |
| **وصف الانحراف** | التصميم البصري الكلي للـ hero تغيّر: خلفية تحوّلت من داكنة إلى فاتحة، حُذفت المشاهد التحريكية (أيقونات المنتجات المتطايرة والسلة)، وأُدرج مكوّن CommercePassport لم يظهر في الـ baseline |
| **التأثير** | الانطباع البصري الأول للمنصة تغيّر بالكامل |

**توصية الاسترجاع (كتوصية فقط):**
إما استرجاع مكوّن `HeroScene` وبنية الـ hero من commit `013f987^` (السابق مباشرةً)، أو اتخاذ قرار واعٍ بتبني التصميم الجديد وتحديث الـ baseline في `docs/design/baseline/`.

### 3. أيقونة زر إجراء ProductTile — **MEDIUM**

| | التفصيل |
|--|---------|
| **الملف** | `app/page.tsx` |
| **السطر الحالي** | 235–242 |
| **الـ baseline** | زر دائري بأيقونة سلة (`ShoppingCart`) ينقل إلى سلة المتجر (`/${storeSlug}/cart`) |
| **الكود الحالي** | رابط بأيقونة سهم يسار (`ArrowLeft`) في `rounded-xl` ينقل إلى صفحة المنتج (`/${storeSlug}/products/${id}`) |
| **الـ commit المسبِّب** | `013f987` (2026-07-30) |
| **وصف الانحراف** | أيقونة الزر تغيّرت من سلة (إيحاء بالإضافة للسلة) إلى سهم (إيحاء بالتصفح). شكل الزر تغيّر من `rounded-xl` — لم يكن دائرياً (`rounded-full`) في الكود السابق أيضاً لكن الأيقونة كانت مختلفة |

**توصية الاسترجاع (كتوصية فقط):**
```tsx
// السطر 236-241 الحالي:
<Link href={productHref} className="grid h-9 w-9 place-items-center rounded-xl bg-emerald-50 ...">
  <ArrowLeft className="h-4 w-4" />
</Link>

// الاسترجاع المقترح (من 013f987^):
<Link href={`/${product.storeSlug}/cart`} className="grid h-9 w-9 place-items-center rounded-xl bg-emerald-50 ..." aria-label={`فتح سلة ${product.storeName}`}>
  <ShoppingCart className="h-4 w-4" />
</Link>
```
