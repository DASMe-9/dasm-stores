**أبرز ميزات Dawn 2.0 ذات الأثر على dasm-stores:**

#### أ) Sticky Add-to-Cart بـ scroll-depth trigger
- الجديد: الشريط يظهر عند تجاوز نسبة تمرير قابلة للضبط (أفضل نتيجة: 40% من طول الصفحة)
- الأثر المقاس: +11% معدل إضافة للسلة على الموبايل في A/B test خلال 3 أسابيع
- الانطباق: `sticky-mini-cart-bar-2026-06-15.md` يغطي وجود الشريط — هذه التفصيلة (scroll-depth trigger) غير موثّقة
- الملف المتأثر: `app/[slug]/products/[productId]/page.tsx`

#### ب) Product Disclosures — قسم جديد على صفحة المنتج
- قسم/block لعرض إفصاحات المنتج أسفل زر الشراء: ضمان، سياسة إرجاع، آمان الدفع
- النمط: صف أفقي من أيقونات + نصوص (pills صغيرة)
- الانطباق: **نعم** — `app/[slug]/products/[productId]/page.tsx` يعرض سياسة الإرجاع بشكل شرطي (`fulfillment_policy`) فقط. لا يوجد صف ثقة ثابت وغير مشروط
- الملف المتأثر: `app/[slug]/products/[productId]/page.tsx` + مكوّن جديد
- Delta جديد؟ **نعم** — لم يُوثَّق سابقاً

#### ج) Color Scheme Tokens (8 named schemes)
- نظام tokens يدعم 8 مجموعات ألوان مسماة عبر الـ theme editor
- الانطباق: **لا مباشر** — dasm-stores يستخدم CSS tokens (var(--primary) إلخ) — معمارية مشابهة موجودة فعلاً
- Delta جديد: لا — لا توجد فجوة محددة

#### د) Architecture: Nested Blocks
- المصمّم يرتّب محتوى الـ sections بـ drag-and-drop دون كود
- الانطباق: **لا** — dasm-stores theme editor موضوع مختلف (visual builder لصفحات المتاجر الفرعية)
