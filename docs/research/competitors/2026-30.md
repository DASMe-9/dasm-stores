### 4. Shopify Dawn — إصلاح HTML الشارات لأغراض SEO والـ Accessibility ⭐ جديد

| التفصيل | القيمة |
|---------|--------|
| المصدر | Shopify/dawn PR #3925 (2026-05-19) |
| الوصف | تغيير مهم: شارتا "Sale" و"Sold Out" كانتا تُرسَّمان دائماً في HTML مع الاعتماد على CSS للإخفاء. الآن تُرسَّم الشارة الصحيحة فقط شرطياً. السبب: crawlers SEO، screen readers، ومساعدي التسوق الـ AI يقرؤون HTML الخام |
| الانطباق على dasm-stores | **نعم** — `components/product/ProductCard.tsx` يُرسم شارة خصم وشارة "مميز" بشرطية (`{discountPct ? ... : null}`) — الوضع الصحيح مطبَّق فعلاً. لكن الـ drift الحرج المكتشف اليوم (خلفية شبه شفافة) يُضعف قراءة الشارة بصرياً |
| ملاحظة تعزيزية | هذا الإصلاح يُعزز ضرورة أن تكون شارات dasm-stores مرئية وواضحة بصرياً (صلبة، تباين عالٍ) — يدعم التوصية بإصلاح drift الخصم المكتشف في هذه الجولة |
| Delta جديد؟ | **نعم (كزاوية تنافسية)** — المنطق الشرطي كان حاضراً، لكن الزاوية الدلالية لم تُوثَّق |
